# RingLink web flasher

Installs RingLink (firmware for the LED Ring v2 FPV gates, ESP32-C3 SuperMini) from Chrome or Edge over USB,
using [ESP Web Tools](https://github.com/esphome/esp-web-tools). Open the page: https://elmagoct.github.io/ringlink/

This repo only holds the published page and firmware files; they are regenerated by the firmware build.
