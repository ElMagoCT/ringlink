LED Rings firmware

RingLink v? for the ESP32-C3 SuperMini in each ring

Install on a ring (USB)

  1. Use Chrome or Edge on a computer.
  2. Ring switch OFF. Plug the ESP32 in with a USB-C data cable.
  3. Click Install and pick the port named USB JTAG/serial debug unit (or ESP32-C3).
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. USB access needs the secure (https) version of this page.

Keeps the ring's name, LED count and order. Brand-new ring: it measures its own strip the first time it runs on its battery. If the board isn't listed: unplug it, hold BOOT, plug it back in, let go, and try again.

Update every ring at once (Wi-Fi)

  1. Download the update file: RingLink update file
  2. Switch the rings on, join Wi-Fi LED-Rings (password ledrings).
  3. In the controls, open Rings → Firmware, pick the file, and tap Update all rings.

Each ring fills up green while it downloads, then restarts. The ring hosting the Wi-Fi goes last.

Control the rings

Join Wi-Fi LED-Rings and the controls usually pop up by themselves. If not:

Open rings.local192.168.4.1

The controls are served by the rings themselves. The ring Wi-Fi has no internet, and browsers don't let a website like this one talk to devices on it, so this page can't be the remote. To get an app icon: open rings.local while you're on LED-Rings, then Share → Add to Home Screen.
